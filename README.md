# ⚔️ GitHub Battle

Compare two GitHub profiles head-to-head and see who comes out on top.

## About

GitHub Battle takes two GitHub usernames and pits them against each other in a stat-based showdown — commits, followers, public repos, total stars, and contribution streak all factor into a weighted score that decides the winner.

Built as a fun way to practice consuming a real external API, handling comparison logic, and shipping a small, complete, shareable tool.

## Features (planned)

- [ ] Search and compare any two public GitHub profiles
- [ ] Category-by-category breakdown (commits, followers, repos, stars, streak)
- [ ] Overall winner based on weighted scoring
- [ ] Shareable result
